The ecosystem reaches beyond the screen.

Honest boundary: the site does not yet claim a verified end-to-end bridge from the canonical Yana Runtime to the exact Wheelbot firmware and hardware configuration.

THE CONTRACT

Reasoning never grants itself power.

A tool name is not permission. Every real action must cross deterministic runtime and human authority boundaries.

01
Model proposes. Runtime decides.Intelligence and authority stay separate.
02
Local-first, not local-only.Use local or cloud models under the same contract.
03
Fail closed. Fail loudly.Missing governance is visible, never silently bypassed.
04
Evidence before completion.“Done” is a claim until artifacts support it.
