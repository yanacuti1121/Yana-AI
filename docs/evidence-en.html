HASH-CHAIN AUDIT LOG

Delete one line, break the whole chain.

Every time an agent calls a tool, one JSONL line is written to the audit log — carrying its own hash and the previous line's hash. Editing or deleting any line breaks the chain, and that's detectable independently, without trusting the log itself.

EVIDENCE ENGINE

Tying results to what actually ran.

A change isn't called "done" just because an agent says so. The evidence engine requires implementation, typecheck, test result and build result — each with its own evidence, never collapsed into a single checkmark.

CALLING IT WHAT IT IS

Tamper-detectable, not tamper-proof.

Yana doesn't advertise the hash chain as unbreakable. It's tamper-detectable: tampering with the log leaves a detectable trace, it doesn't mean tampering is impossible. That distinction is deliberate in how this site talks about it.

YANA PRINCIPLE

Evidence first, claims second.

No real command run this session means no "pass" claim — evidence always comes before the claim, never the other way around.
