01 — THE BOUNDARY

A proposal is not execution.

A model creates a proposal. Yana checks authority, grants a bounded capability, executes through the appropriate surface, then writes a receipt. When policy requires it, a human approves the decision.

INTELLIGENCE

Model-neutral

Cloud or local intelligence can change without moving the system's authority boundary.

AUTHORITY

Human-governed

Final authority is not conflated with a model's ability to reason.

EVIDENCE

Inspectable

Every action connects to a decision, a capability and an inspectable receipt.

02 — TERMINAL TOOLS

You don't need Studio to use Yana.

Yana AI has two independent CLIs, each installed through its language's standard package manager — neither touches Yana Studio.

PIP · REPOSITORY GOVERNANCE

yana-ai — apply the governance layer to a project

Installs the Python CLI yana-ai, used to wire rules, hooks, agents, skills and commands into one specific project and check its integrity — everything stays scoped to that project, not your machine or other projects.

pip install yana-ai cd your-project yana-ai install # wires the hooks, ~60 seconds yana-ai doctor . # integrity check

After yana-ai install, your AI agent (Claude Code, Cursor, Codex, Antigravity...) gets intercepted if it tries a dangerous command — hard-blocked on Claude Code/Cursor, advisory on Codex/Antigravity — and logged, entirely locally with no LLM call.

CARGO · RUNTIME & ORCHESTRATION

yana-rt — the canonical TurnEngine and terminal workspace

Installs the Rust CLI yana-rt (the same binary Yana Studio runs internally) — both a terminal workspace for running local models and a task-orchestration tool with direct command-line access to evidence, capability and memory, no Studio window needed.

cargo install yana-rt yana-ai-rt --provider ollama # terminal workspace, local model yana-rt route classify "fix auth" yana-rt mission create "add-auth"

The terminal workspace has streaming, mid-run cancellation, multiple tabs, multiple sessions, and live model switching. route/mission classify and create dependency-aware tasks through the same runtime Studio uses.
