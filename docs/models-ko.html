제공자별 기본 모델

제공자를 선택하세요 —
Yana가 기본 모델을 선택합니다.

각 제공자는 기본 모델을 선언합니다. Anthropic을 고르면 Yana가 해당 제공자의 기본 모델을 사용합니다. 카탈로그에서 정확한 모델 이름을 찾아 외울 필요가 없습니다.

로컬 우선

Ollama도 동등하게 지원합니다.

로컬 제공자도 클라우드 제공자와 같은 권한 모델을 사용합니다. 로컬이라는 이유로 권한 검사를 우회하지 않으며 클라우드에만 별도의 규칙을 적용하지 않습니다.

Yana 원칙

모델은 단지 하나의 교체 가능한 구성 요소일 뿐입니다.

새로운 제공자 게이트웨이(OpenRouter)는 아직 모든 호출의 처리 경로가 아닙니다. 이 사이트는 해당 계층의 완성도를 과장하지 않습니다.
