Bản Đồ Lệnh Yana AI

Hai bề mặt lệnh khác nhau, dễ nhầm với nhau: lệnh CLI thật gõ ở terminal (yana-ai / yana-rt) và slash command chỉ dùng bên trong một phiên Claude Code.

Phát hiện đáng chú ý (chưa sửa, để anh quyết): binary target/release/yana-rt trên máy có thể cũ hơn source HEAD. bin/yana luôn ưu tiên binary release trước debug (xác nhận tại bin/yana:30) — nên sau cargo build (build debug), lệnh yana-ai os status hay các lệnh Rust mới vẫn có thể gọi nhầm vào binary release cũ và báo "không nhận lệnh". Cách né tạm: cargo build --release trước khi test lệnh mới, hoặc xoá target/release/yana-rt để buộc fallback sang debug.
