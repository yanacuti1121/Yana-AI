컴포넌트 시스템

여섯 개의 컴포넌트 상자에서 멈추지 않습니다.

컴포넌트 라이브러리는 레이아웃, 콘텐츠, 입력, 내비게이션과 피드백으로 묶는 방향입니다. 긴 목록을 스크롤하지 않고 필요한 항목을 빠르게 찾을 수 있도록 합니다.

목표 작업 흐름

디자인 → 코드 → 실행 → 검토.

선택한 요소에 AI가 직접 변경을 제안하고, 코드 패치와 실행 미리보기를 제공하며 변경을 되돌릴 수 있게 하는 것이 목표입니다. 아직 완성된 기능이 아니라 개발 중인 방향입니다.

1 · 선택컴포넌트
2 · 요청자연어로 변경 요청
3 · 제안코드 패치
4 · 검토미리보기 + 되돌리기

감사의 말

Yana AI는 Apache 2.0, MIT 및 기타 허용 라이선스 하에 라이선스된 프로젝트를 포함하여 오픈소스 커뮤니티의 아이디어, 패턴 및 도구를 기반으로 구축되었습니다. 모든 제3자 소스는 각 라이선스에 따라 준수하여 사용됩니다. 이 프로젝트는 개인이나 조직의 지적 재산권을 복사, 오해하거나 침해할 의도가 없습니다. 특정 프로젝트가 디자인 결정에 직접적인 영향을 미친 경우, 관련 소스 파일 및 규칙 문서에 출처가 명시됩니다.
