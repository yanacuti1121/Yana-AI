FROM TERMINAL TO RUNTIME

Yana began as a conversation in the terminal.

That was the first way to interact: talking to the AI right where the work happens. When the AI needed to touch files and tools, Yana grew a runtime layer to control its actions. Studio came later, bringing the same workflow to a visual interface.

CORE CAPABILITIES

Authority travels with every action.

Yana turns operating boundaries into steps you can see and inspect.

01 / SCOPE

Grant exactly the right capability.

An agent can only call tools and paths inside the declared scope. Authority does not expand on its own because of a model's answer.

Learn about Governance ↗
02 / DECISION

Block, allow or ask.

Requests pass through the authority layer. When a user decision is needed, execution pauses and waits for approval.

Leave a trace.

Proposals, decisions and results can be traced through the record and the evidence receipt.
