Yana AI 명령어 목록

Yana에는 서로 다른 두 종류의 명령이 있습니다. 터미널에서 실행하는 CLI 명령(yana-ai / yana-rt)과 Claude Code 세션 안에서만 사용하는 슬래시 명령입니다.

59최상위 명령 — yana-ai CLI
34최상위 명령 — yana-rt (Rust)
170슬래시 명령 — Claude Code
5실행 파일 진입점
알려진 문제(아직 수정되지 않음): 로컬의 target/release/yana-rt 실행 파일이 소스 HEAD보다 오래되었을 수 있습니다. bin/yana는 debug보다 release 실행 파일을 우선 사용합니다(bin/yana:30 참조). 따라서 cargo build로 디버그 빌드를 만든 뒤에도 yana-ai os status 같은 새 Rust 명령이 이전 릴리스 실행 파일로 전달되어 인식되지 않을 수 있습니다. 새 명령을 테스트하기 전에 cargo build --release를 실행하거나 target/release/yana-rt를 제거해 디버그 빌드를 사용하세요.

5개의 진입점

터미널 명령역할
yana-ai사용하기 쉬운 공개 CLI — 최상위 명령 59개, 대부분 yana-rt로 전달
yana-rtRust 런타임 직접 실행 — 최상위 명령 34개(기본 32개, 기능 플래그가 필요한 mcp와 remote 2개)

yana-ai-install내부 설치 프로그램
pty_bridgeElectron 데스크톱용 PTY 브리지 — 공개 CLI는 아닙니다.

59개와 34개를 합산하면 안 됩니다. 대부분의 yana-ai 명령은 yana-rt로 전달되는 사용하기 쉬운 진입점입니다(예: yana-ai task → rt task).

주요 명령 트리
