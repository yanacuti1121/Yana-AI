PRIVACY

Data currently used by this website.

This page describes the current static website. It will be updated before any account service is deployed.

Browser storage

The website uses localStorage to remember the selected language and whether the announcement bar has been dismissed. This data remains in your browser.

Release data

The download page may call the GitHub Releases API to display public release files. That request is sent directly to GitHub and is governed by GitHub's policies.

Accounts

No web account service is deployed. The current account interface does not send or store names, email addresses or passwords. This notice must be updated before email, Google or GitHub authentication is enabled.

Contact

When you choose to contact Yana by email, phone, Facebook, TikTok or GitHub, your data is handled by the channel you select and its corresponding policy.
