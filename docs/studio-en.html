A CLEAR WORKFLOW

From goal to result.
Every step in view.

Studio brings your project, model, work and decisions into one space. Each step has a place, so you can see what is happening before allowing it to continue.

  1. 01 / PROJECT

    Open a real folder

    Choose a project on your computer. Studio stores a reference to the folder without copying the repository elsewhere.

  2. 02 / MODEL

    Choose intelligence

    Browse cloud or local models from the runtime catalog. Changing models does not silently change execution authority.

  3. 03 / WORK

    Work with context

    Talk with Yana, open files in the editor, inspect Git and use your own terminal from the same workspace.

  4. 04 / REVIEW

    Keep the decision

    When AI needs a governed capability, Studio presents the request for you to inspect and decide within the runtime boundary.

A CLEAR AUTHORITY BOUNDARY

Your terminal.
AI actions.

IN THE DEVELOPMENT BUILD

A real workspace

  • Local projects and files, with editor conflict protection.
  • Real terminal sessions with tabs, grid layout, search and scrollback.
  • Chat through the Yana runtime, conversation history and stop.
  • Read-only Git status, worktrees and diffs.
STILL IN PROGRESS

The next layers

  • Design Canvas remains experimental.
  • Fuller permission and evidence surfaces are in development.
  • Signed installers, updates and real-app Linux and Windows verification are not complete.
  • There is no Yana Cloud account or data sync yet.

The development build has been checked on macOS arm64. Model and execution capabilities depend on the current runtime, provider and configuration.
