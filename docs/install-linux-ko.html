설치 방법을 선택하세요. Debian/Ubuntu에서는 .deb 패키지를 sudo dpkg -i로 설치할 수 있습니다. 대부분의 배포판에서는 .AppImage에 chmod +x로 실행 권한을 준 뒤 파일을 직접 실행할 수 있습니다.

시스템Linux x86_64 — Debian/Ubuntu (.deb) 또는 AppImage를 지원하는 모든 배포판.
서명 상태빌드는 코드 서명되지 않았으며 어떤 앱 스토어에도 등록되어 있지 않습니다.
검증파일의 SHA-256 해시를 릴리스에 포함된 SHA256SUMS와 비교하세요.
