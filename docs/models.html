TỰ CHỌN MODEL THEO PROVIDER

Chọn provider —
Yana tự biết dùng model nào.

Mỗi provider tự khai báo model mặc định của mình. Chọn "Anthropic", Yana tự dùng model Anthropic phù hợp nhất — không cần tự tra catalog, không cần nhớ tên model chính xác.
