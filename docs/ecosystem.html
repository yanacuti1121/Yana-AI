BỀ MẶT NGƯỜI DÙNG

4 cách chạm vào Yana.

Mỗi bề mặt lộ ra một tập quyền khác nhau — không bề mặt nào mạnh như nhau.

DESKTOP

Yana Studio 1.5

Electron app: chat, code editor, terminal thật (PTY), Git, quản lý model, permissions, Design Canvas thử nghiệm.

renderer (React/TS) host (Electron main) spawn yana-rt binary

CLI

Runtime CLI (yana-rt)

Binary Rust cài qua cargo install yana-rt. Cùng TurnEngine, cùng authority chain với Studio — không phải bản triển khai riêng.

cargo install yana-rt yana-rt chat

PHYSICAL AI

Yana Wheelbot

Robot ESP32-S3 thật, firmware thật. Có device bridge WebSocket/MCP riêng — chưa xác minh đi qua cùng TurnEngine end-to-end.

ESP32-S3 firmware ● exists bridge ◐ evolving

WEB

Website này

Static HTML, không framework. Trang tải xuống gọi trực tiếp GitHub Releases API — không có server Yana đứng giữa.

docs/*.html assets/ecosystem-pages.js GitHub Releases API
