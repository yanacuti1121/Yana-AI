TYPED TASK GRAPH

Dependency là dữ liệu thật.

Task hỗ trợ quan hệ blocks, related, parent-child và discovered-from; readiness được suy ra từ graph thay vì nhập tay.

Blocks

Không chạy bước kiểm thử trước khi phần triển khai sẵn sàng.

implement └── blocks → verify

Discovered from

Việc mới tìm thấy trong quá trình làm vẫn giữ được nguồn gốc.

fix auth └── discovered-from review logs

Parent–child

Mission lớn được chia nhỏ mà không mất cấu trúc mục tiêu.

release ├─ package ├─ verify └─ publish
