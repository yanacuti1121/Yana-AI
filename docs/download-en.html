CLI & REPOSITORY TOOLS

Install the command-line tools (PyPI & Cargo)

These two tools work on their own and do not require the Yana app. Use them to add safety rules and monitoring to your repository.

PYTHON PACKAGE INDEX

yana-ai: an AI guard for your repository

Install the Python CLI for safety rules (Truth Gate, Action Gate), slash commands and drift checks before an AI edits your code.

# 1. Install from PyPI:
pip install yana-ai
# 2. Set it up in your project folder:
cd your-project
yana-ai install
Open the PyPI page ↗
RUST CRATE

yana-rt: runtime and terminal

Yana's core runtime: streaming chat with a local model (Ollama) or a cloud one, every command waits for your approval.

# 1. Install the runtime with Cargo:
cargo install yana-rt
# 2. Open a chat terminal with a local model:
yana-rt chat --provider ollama
Open the crate page ↗

🔒 First launch on macOS

The first time, right-click (Control-click) Yana in Applications and choose Open. The app is signed ad-hoc and not notarized by Apple, so macOS warns once. If it was already blocked: System Settings → Privacy & Security → Open Anyway.

🧩 Studio comes inside Yana

Yana Studio lives inside Yana.app and updates together with Yana; there is no separate download anymore. Click Code editor in Yana to open it.

🦙 AI on your own machine

Use offline models through Ollama, or cloud models with your own API key. API keys are kept in the macOS Keychain.
