MODELS & PROVIDERS

Change the model.
Not the system.

Yana doesn't lock into one model. The provider is a replaceable abstraction — authority, context and evidence live outside the model, independent of whichever one is running.

PER-PROVIDER DEFAULT MODEL

Pick a provider —
Yana already knows which model to use.

Every provider declares its own default model. Pick "Anthropic" and Yana automatically uses the right Anthropic model — no catalog lookup, no need to remember an exact model name.

LOCAL-FIRST

Ollama isn't a second-class citizen.

Local providers go through the same authority model as cloud providers — no separate shortcut for local, no separate rules for cloud.

YANA PRINCIPLE

The model is just one replaceable component.

The newer provider gateway (OpenRouter) isn't yet the dispatch path for every call — this site doesn't overstate how mature that abstraction is.
