THE STACK

Model chỉ là một thành phần có thể thay.

Authority và trạng thái hệ thống sống bên ngoài model để đổi provider hoặc agent mà không mất ranh giới.

Intelligence plane

Provider local và cloud dùng chung authority model; provider gateway mới vẫn chưa là dispatch path cho mọi call.

OpenAI · Anthropic Groq · Gemini Ollama · local

Execution plane

Rust TurnEngine quản lý typed turns, streaming, cancellation và canonical capability.

turn → stream → tool loop → cancel → partial output

Authority plane

Giám Thị, YanaAuthorityChain, approval, leases và HALT giữ quyền ngoài suy luận.

human ↓ Giám Thị ↓ Yana control plane
