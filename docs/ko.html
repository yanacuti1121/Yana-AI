60초 동안 Yana를 직접 살펴보세요.

페이지 제목을 바꾸는 작은 작업을 체험해 보세요. 요청과 제안을 확인하고 실행 권한을 결정한 뒤, 결과와 증거 기록을 살펴봅니다.

01 / 요청

하나의 요청으로 시작하세요.

작은 작업으로 전체 흐름을 살펴봅니다. 예시 프로젝트의 파일 하나에서 제목을 바꿉니다.

02 / 제안

AI가 하려는 일을 먼저 확인하세요.

권한을 허용하기 전에 변경 제안과 정확한 작업 범위를 확인합니다.

  • 범위demo/index.html
  • 기능file.write
  • 변경제목 한 줄

03 / 권한

결정권은 당신에게 있습니다.

한 번 허용하거나, 추가 확인을 요청하거나, 거부할 수 있습니다. 선택에 따라 결과가 달라집니다.

Yana · 변경 제안 예시

04 / 결과

변경 사항을 직접 확인하세요.

허용하면 예시의 제안된 한 줄만 바뀝니다. 거부하면 예시 파일은 그대로 유지됩니다.

Yana · 변경 제안 예시
demo/index.html

허용됨: 예시에서 한 줄이 바뀝니다.

− <h1>안녕하세요.</h1>+ <h1>안녕하세요, Yana.</h1>

거부됨: 예시 파일은 그대로 유지됩니다.

<h1>안녕하세요.</h1>

필요한 기능만 허용합니다.

에이전트는 선언된 범위 안의 도구와 경로만 사용할 수 있습니다. 모델의 응답만으로 권한이 확대되지 않습니다.
