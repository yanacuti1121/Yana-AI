명확한 작업 흐름

목표에서 결과까지.
모든 단계를 한눈에.

Studio는 프로젝트, 모델, 작업, 결정을 하나의 공간에 모읍니다. 각 단계가 어디서 일어나는지 보고 계속 진행할지 결정할 수 있습니다.

  1. 01 / 프로젝트

    실제 폴더 열기

    컴퓨터의 프로젝트를 선택합니다. Studio는 저장소를 다른 곳으로 복사하지 않고 폴더 위치만 기억합니다.

  2. 02 / 모델

    모델 선택

    런타임 목록에서 클라우드 또는 로컬 모델을 찾을 수 있습니다. 모델을 바꿔도 실행 권한은 몰래 바뀌지 않습니다.

  3. 03 / 작업

    맥락을 보며 작업하기

    같은 워크스페이스에서 Yana와 대화하고 파일을 열고 Git을 확인하며 자신의 터미널을 사용할 수 있습니다.

  4. 04 / 검토

    결정권 유지

    AI가 관리 대상 기능을 필요로 하면 Studio가 요청을 보여 줍니다. 사용자는 런타임의 경계 안에서 내용을 확인하고 결정합니다.

명확한 권한 경계

사용자의 터미널.
AI의 행동.
서로 다른 경로.

사용자는 터미널에서 직접 작업할 수 있습니다. Yana의 행동은 런타임과 기능 제어를 거칩니다. AI의 출력만으로 셸 명령이 실행되지는 않습니다.

Yana의 행동 관리 방식 ↗
사용자 경로터미널입력한 내용 → 사용자 셸
Yana 경로런타임제안 → 권한 확인 → 통제된 실행

1.6.2 릴리스에서 사용 가능

현대적 워크스페이스 & 에이전트 콕핏

  • Monaco Editor, LSP, 프로젝트 탐색기, 다중 탭을 갖춘 완전한 VS Code 코어 워크스페이스.
  • 통합 Yana Agent 콕핏: Act(실행) 모드 및 Careful Reviewer(심층 검토) 모드 지원.
  • 상태 표시줄 원격 감시: 정책(SUPERVISED), 런타임 상태, 실시간 감사 카운터(500✓ 0✕) 표시.
  • 독립 업데이트 아키텍처: 데스크톱 설치 프로그램과 핵심 yana-rt를 분리하여 전체 앱 재설치 없이 런타임 즉시 업그레이드 지원.
  • 탭, 분할 화면, 스크롤백 및 기능 제어가 적용된 실제 터미널.
개발 진행 중

다음 단계

  • Design Canvas 시각적 레이아웃 워크플로우 성능 고도화.
  • 팀 및 기업 환경을 위한 다계층 거버넌스 대시보드 확장.
  • 기기 간 워크스페이스 환경설정 및 프로필 자동 동기화.
  • 추가 로컬 LLM 런타임 및 커스텀 추론 엔드포인트 연동.

최신 릴리스는 macOS (Apple Silicon), Windows, Linux에서 검증되었습니다. 모델 실행 기능은 설정된 Yana Runtime 거버넌스 규칙을 따릅니다.
