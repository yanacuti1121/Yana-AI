Mỗi công cụ gọi qua Yana đều phải đi qua 6 chốt chặn thẩm định độc lập theo thứ tự nghiêm ngặt.

L0 · BẤT BIẾN & GHI VẾT

Hash-Chained Audit Trail

Mọi tool call đều ghi nhận nhật ký băm SHA-256 chuỗi liên kết. Nếu sửa đổi hay xóa dù chỉ 1 dòng, chuỗi hash sẽ lập tức bị đứt gãy.

sha256(prev_hash + tool_call)
✓ immutable log created
L1 · BẢO VỆ DỮ LIỆU NHẠY CẢM

Token & Scope Guard

Cảnh báo và phong tỏa ngay lập tức nếu AI cố tình đọc các tệp chứa thông tin bí mật: .env, private key, credential hoặc ghi đè mã nguồn dự án.

read_file(".env.production")
⚠ WARN: Credential leak blocked
L2 · RỦI RO PHẠM VI DỰ ÁN

Blast Radius Policy

Chặn các thay đổi lan rộng vượt tầm kiểm soát. Nếu 1 lệnh chạm quá 50 file hoặc sửa nhầm file ngoài phạm vi cấp phép, bắt buộc con người duyệt.

modified_files: 84 (> 50 threshold)
⚠ GATE: Human explicit OK required
L3 · CỔNG BẢO CHỨNG SỰ THẬT

Truth Gate L3 Engine

Cấm tuyệt đối tuyên bố ảo ("xong", "đã pass test"). AI buộc phải đính kèm bằng chứng thực thi thực tế (test runner output, file diff) trong cùng lượt.

claim: "All 120 tests passed"
✓ Evidence verified: exit 0 (120/120)
L4 · CHẶN DEPLOY LÊN MÂY

Production Deploy Gate

Khóa cứng mọi lệnh phát hành hoặc tương tác hạ tầng đám mây: kubectl, docker push, gcloud, fly deploy, vercel --prod.

kubectl apply -f prod.yaml
✕ HARD BLOCK: Deploy not permitted
L5 · CHỐT CHẶN PHÁ HOẠI

Destructive Action Interceptor

Chặn đứng trước khi lệnh thực thi: rm -rf /, git push --force, DROP TABLE, curl | bash. Không có ngoại lệ.

rm -rf /Users/vutam/project
✕ EMERGENCY HALT: Destructive regex match
