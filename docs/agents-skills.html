AGENTS

Dispatch đồng bộ, không phải swarm nền.

Main agent gọi một subagent cho một tác vụ cụ thể, subagent trả về báo cáo dạng text, main agent quyết định bước tiếp theo. Không có tiến trình subagent nào tồn tại giữa các lần dispatch.

Đọc-only theo mặc định

Subagent không được Write/Edit, không git commit/push, không chạy hook — chỉ main agent mới có quyền đó.

subagent: read, grep, glob main agent: write, commit, push

Báo cáo dạng text, không phải diff

Subagent trả findings + evidence + đề xuất bằng văn bản. Main agent tự áp dụng thay đổi, không nhận diff trực tiếp từ subagent.

Findings Evidence & Reasoning Recommended actions "No files were modified."

Độ sâu delegation giới hạn

Root agent → subagent A → subagent B là tối đa. Không cho phép chuỗi dispatch vô hạn.

depth 0 → 1 → 2 → 3 (max)

SKILLS

Kiến thức nạp theo yêu cầu,
không phải hook tự động.

Một skill là một file hướng dẫn có mục đích, điều kiện trigger, quy tắc và cách xác minh rõ ràng. Nó không tự chạy — chỉ được đọc khi câu hỏi của người dùng khớp trigger. 2.026 skill trong repo này bao phủ hàng trăm domain, từ frontend, security tới robotics.

SKILL BÊN NGOÀI

Vendor có kiểm chứng, không nhét bừa.

Khi đưa một skill mã nguồn mở vào, Yana kiểm tra license trước, giữ nguyên nội dung gốc (không chỉnh sửa ngầm), và ghi rõ nguồn trong một file ATTRIBUTION.md đi kèm.

1. Kiểm license

Chỉ vendor license cho phép tái phân phối (MIT, Apache 2.0...). Không copy code không rõ license.

2. Giữ nguyên bản gốc

Nội dung skill vendor verbatim — không chỉnh sửa để "cải thiện" ngầm, tránh lệch khỏi upstream.

3. Kiểm trùng trigger

Nếu trùng phạm vi với skill có sẵn, thêm ghi chú "Do NOT use for" chéo giữa hai skill thay vì để agent chọn ngẫu nhiên.
