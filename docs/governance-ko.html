감독자 · GIÁM THỊ

AI 세션 밖에서 동작하는 감독자.
세션이 끝나도 계속 작동합니다.

Claude, Codex, Cursor의 훅은 공유된 안전 상태를 따를 뿐 스스로 HALT 권한을 갖지는 않습니다. HALT 권한은 AI 세션 밖에서 운영체제 수준으로 독립 실행되는 감독자(Giám Thị)에게 있습니다.

주기적 상태 확인

CPU, RAM, 디스크, GPU, 하트비트 SLO와 실행 중인 세션 수를 수집합니다. 변조를 감지할 수 있는 실행 증거 체인도 남깁니다.

yana-rt os supervisor tick → 상태 확인 기록 → 변조 감지 가능한 체인

공유 잠금 파일로 HALT

이상 징후 감지 → 공유 잠금 파일 생성 → 모든 Claude, Codex, Cursor 훅이 즉시 잠금 적용.

.claude/state/ GIAMTHI_HALT.lock

잠금 해제에는 사람이 절차에 따라 승인해야 합니다

HALT를 해제하려면 잠금을 없애기 전에 해제 주체와 이유를 기록해야 합니다. 에이전트는 스스로 잠금을 풀 수 없습니다.

잠금 해제 조건 주체 + 이유 해제 전에 기록

권한 체인

허용, 승인 요청, 거부.
회색 지대가 없습니다.

YanaAuthorityChain은 실제 행동 전에 결정론적인 사전 검사를 실행합니다. 감독자의 HALT는 항상 최우선입니다.

기능 명세

모든 행동에는 공식 이름, 위험 수준과 승인 조건이 있습니다.

기능 file.write 위험 상태 변경 승인 필요

범위가 정해진 기능 사용 권한

권한은 주체, 범위와 시간으로 제한되며 취소할 수 있습니다.

주체 현재 세션 범위 /workspace 기간 27분 취소 가능

오류를 분명히 드러냅니다

권한 관리가 누락되면 명확하게 드러나야 합니다. 권한 검사를 조용히 건너뛰지 않습니다.

가드 누락 → 중지 거부 → 명확하게 표시 HALT → 최우선
