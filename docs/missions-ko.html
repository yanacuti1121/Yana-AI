형식이 정의된 작업 그래프

작업 간 의존성은 실제 데이터로 남습니다.

작업은 차단, 관련, 상위·하위와 파생 관계를 지원합니다. 실행 준비 상태를 직접 입력하지 않고 그래프에서 계산합니다.

차단됨

다른 작업에서 파생됨

진행 중 발견된 작업에도 출처를 남깁니다. 새 작업이 혼란 속에서 사라지지 않습니다.

인증 수정 └── 발견한 작업 로그 검토

상위·하위 작업

큰 미션을 작은 작업으로 나누어도 전체 목표의 구조는 유지합니다.

릴리스 ├─ 패키징 ├─ 검증 └─ 공개

감사의 말

Yana AI는 Apache 2.0, MIT 및 기타 허용 라이선스 하에 라이선스된 프로젝트를 포함하여 오픈소스 커뮤니티의 아이디어, 패턴 및 도구를 기반으로 구축되었습니다. 모든 제3자 소스는 각 라이선스에 따라 준수하여 사용됩니다. 이 프로젝트는 개인이나 조직의 지적 재산권을 복사, 오해하거나 침해할 의도가 없습니다. 특정 프로젝트가 디자인 결정에 직접적인 영향을 미친 경우, 관련 소스 파일 및 규칙 문서에 출처가 명시됩니다.
