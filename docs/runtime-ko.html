오류를 분명히 드러냅니다

권한 관리가 누락되면 명확하게 드러나야 합니다. 권한 검사를 조용히 건너뛰어서는 안 됩니다.

가드 누락 → 중지 거부 → 명확하게 표시 HALT → 최우선

작업 연속성
