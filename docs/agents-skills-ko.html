에이전트

동기식 호출이며, 백그라운드의 에이전트 군집이 아닙니다.

주 에이전트가 특정 작업을 위해 하위 에이전트를 호출하면 하위 에이전트가 텍스트 보고서를 반환합니다. 다음 단계는 주 에이전트가 결정합니다. 호출 사이에는 하위 에이전트 프로세스가 남지 않습니다.

기본적으로 읽기 전용입니다

하위 에이전트는 파일 쓰기와 편집, Git 커밋과 푸시, 훅 실행을 할 수 없습니다. 해당 권한은 주 에이전트에게만 있습니다.

하위 에이전트: read, grep, glob 주 에이전트: write, commit, push

변경 사항(diff)이 아닌 텍스트 보고서입니다

하위 에이전트는 발견 사항, 증거와 권고를 글로 반환합니다. 주 에이전트가 직접 변경을 적용하며 하위 에이전트에서 변경 패치를 받지는 않습니다.

발견 사항 증거와 근거 권고 사항 “파일은 변경하지 않았습니다.”

제한된 위임 깊이

최대 위임 깊이는 루트 에이전트 → 하위 에이전트 A → 하위 에이전트 B입니다. 끝없는 위임은 허용하지 않습니다.

위임 단계 0 → 1 → 2 → 3 (최대)

외부 스킬

검증된 외부 코드를 선별해 가져옵니다.

오픈 소스 스킬을 가져오기 전에 라이선스를 확인합니다. 원문은 수정하지 않으며 출처를 함께 제공되는 ATTRIBUTION.md 파일에 기록합니다.

1. 라이선스 확인

재배포를 허용하는 라이선스 (MIT, Apache 2.0 등)만 사용합니다. 라이선스가 불분명한 코드는 복사하지 않습니다.

2. 원문 유지

외부에서 가져온 스킬은 원문을 유지합니다. 업스트림과 달라지는 변경을 조용히 추가하지 않습니다.

3. 트리거 중복 확인

기존 스킬과 범위가 겹치면 서로의 사용 제외 범위를 명시합니다. 에이전트가 임의로 고르도록 두지 않습니다.
