이 웹사이트가 현재 사용하는 데이터.

이 페이지는 현재 정적 웹사이트를 설명합니다. 계정 서비스가 배포되기 전에 업데이트될 예정입니다.

브라우저 저장소

웹사이트는 localStorage에 언어 선택과 알림 표시 상태를 저장합니다. 이 데이터는 브라우저에 남습니다.

릴리스 데이터

다운로드 페이지는 공개 출시 파일을 표시하기 위해 GitHub Releases API를 호출할 수 있습니다. 이 요청은 GitHub에 직접 전송되며 GitHub의 정책에 따라 관리됩니다.

계정

웹 계정 서비스가 배포되지 않았습니다. 현재 계정 인터페이스는 이름, 이메일 주소 또는 비밀번호를 전송하거나 저장하지 않습니다. 이 알림은 이메일, Google 또는 GitHub 인증이 활성화되기 전에 업데이트되어야 합니다.

문의

이메일, 전화, Facebook, TikTok 또는 GitHub으로 문의하면 해당 채널의 정책에 따라 데이터가 처리됩니다.
